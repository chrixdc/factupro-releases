# FactuPro — Lanzamientos

Instaladores de **FactuPro**, sistema de facturacion y administracion comercial.

Desarrollado por **Argos Core**.

## Descargar

Las versiones estan en la seccion **Releases** de este repositorio.

- **FactuPro-x.x.x-Instalador.exe** — instalacion normal en la computadora del negocio
- **FactuPro-x.x.x-portable.exe** — se ejecuta desde un pendrive, sin instalar

## Actualizaciones

El programa se actualiza solo: comprueba si hay version nueva al abrir, la descarga
en segundo plano y la instala al cerrar. No hay que hacer nada.
